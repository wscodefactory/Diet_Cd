# 유료 항목 기록 (구현 보류)

개발 원칙: **개발 과정에서 비용이 드는 항목은 기록만 하고 구현하지 않는다.**
프로토타입은 아래 항목을 모두 예시 데이터(mock)와 규칙 기반 로직으로 대신한다.
도입을 결정하면 이 문서에서 항목을 옮겨 구현 계획에 반영한다.

> 가격은 시기와 요금제에 따라 바뀌므로 여기에 금액을 적지 않았다. 도입 시점에 각 서비스의 공식 요금표를 확인할 것.

## 무료로 쓸 수 있을지 나중에 확인할 후보

아래는 무료 공개 자료/API로 알려져 있지만, 이용 조건과 호출 한도를 도입 전에 직접 확인해야 한다.
프로토타입에서는 연결하지 않았다 (백엔드가 없고 API 키 보관 위치가 정해지지 않았기 때문).

- PubMed(NCBI E-utilities), Semantic Scholar 등 공개 논문 검색 API
- 식품의약품안전처 식품영양성분 데이터베이스(공공데이터), USDA FoodData Central
- 무료 요금제가 있는 호스팅(정적 사이트) — 요금제 한도 확인 필요

## 앱(Android/iOS) 메모

프론트엔드가 React + TypeScript이므로 이후 React Native 또는 Capacitor로 앱을 감쌀 수 있다.
빌드 도구 자체는 무료지만 스토어 배포 계정(11, 12)은 유료라 이번 프로토타입에서는 제외했다.
