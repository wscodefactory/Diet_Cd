## 참고: 무료지만 가입이나 키 발급이 필요한 것 (아직 연결 안 함)

- 식품의약품안전처 식품영양성분 DB 공공 API: 무료이나 키 발급 필요.
- PubMed E-utilities: 무료. 논문 메타데이터 조회 가능하나 원문 확인과 요약에는 LLM 비용이 따름.

## 로그인·회원가입을 실제로 붙일 때 후보 (아직 연결 안 함)

정적 사이트(GitHub Pages)만으로는 안전한 로그인을 만들 수 없어서, 아래 중 하나를 골라 `src/auth/service.ts`의 `AuthService`를 구현하면 됩니다.
무료 구간의 한도와 조건은 바뀔 수 있으니 고를 때 각 서비스 요금 페이지를 다시 확인해야 합니다.

- Firebase Authentication: 이메일·비밀번호 가입과 이메일 인증 메일 발송을 기본 제공. 무료 구간 있음(일일 한도 있음), 넘으면 유료.
  기본 인증 메일은 '링크 클릭' 방식이라 6자리 코드 방식으로 바꾸려면 Cloud Functions(유료 요금제 필요)가 따름.
- Supabase Auth: 이메일 가입·인증(링크 또는 OTP 코드)을 기본 제공. 무료 구간 있음, 기본 메일 발송은 시간당 몇 통 수준으로 제한돼서
  실제 운영에는 별도 SMTP(이메일 발송 서비스) 연결 필요. 미사용 프로젝트 일시정지 같은 무료 구간 조건 있음.
- 자체 서버 + 이메일 발송 서비스: 서버 호스팅 비용과 Resend·SendGrid·Amazon SES 같은 발송 비용(무료 구간이 있는 곳도 있음).
- 어느 쪽이든 아이디·비밀번호 규칙은 `src/auth/rules.ts`와 같게 서버에서도 다시 검사해야 함.
