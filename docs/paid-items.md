# 유료 항목 기록 (구현하지 않음)

개발 중 비용이 발생하는 항목은 구현하지 않고 여기에 기록만 합니다.
프로토타입에서는 모두 목(mock) 데이터나 단순 규칙으로 대체했습니다.

| 항목 | 용도 | 프로토타입의 대체 방식 | 대체 코드 위치 |
| --- | --- | --- | --- |
| LLM API (Claude 등) | 식단 생성, 추천 이유 문장 작성, 대안 제안 | 규칙 기반 계산과 고정 문장 템플릿 | `src/plan.ts` |
| 논문·자료 검색 API (유료 학술 DB, 검색 API) | 근거 자료 검색, 원문 확인, 요약 | 손으로 적은 예시 출처 목록. 화면에 '예시' 배지 표시 | `src/data.ts` 의 `REFS` |
| 음식 사진 (스톡 이미지 구매, 이미지 생성 API, 촬영) | 결과 화면 상단 음식 사진 | 이모지로 만든 자리표시 이미지. '예시 이미지' 표기 | `src/ui.tsx` 의 `Photo` |
| 영양성분 데이터베이스 (상용 DB 라이선스) | 식품별 정확한 영양값과 제공량 | 손으로 적은 근사값. 화면에 '예시 값' 표기 | `src/data.ts` 의 `ITEMS` |
| 식재료 가격 데이터 (유통사·시세 API) | 예산 반영 | 손으로 적은 가상 가격 | `src/data.ts` 의 `ITEMS` |
| 반려동물 사료 제품 DB | 제품별 칼로리 밀도, 성분 | 건식 3.5 kcal/g, 습식 0.9 kcal/g 가정값 | `src/plan.ts` |
| 백엔드·호스팅·DB (서버, 도메인, 스토리지) | 계정, 데이터 저장, 배포 | 브라우저 localStorage 저장, 로컬 실행만 | `src/ui.tsx` 의 `useLocal` |
| 앱스토어 개발자 계정 (Apple, Google) | 네이티브 앱 배포 | 반응형 웹으로만 제공 | 없음 |
| 전문가 검수 (영양사, 수의사 자문) | 추천 로직과 문구 검증 | 없음. 화면에 참고용이라는 안내 표시 | 없음 |

## 참고: 무료지만 가입이나 키 발급이 필요한 것 (아직 연결 안 함)

- 식품의약품안전처 식품영양성분 DB 공공 API: 무료이나 키 발급 필요.
- PubMed E-utilities: 무료. 논문 메타데이터 조회 가능하나 원문 확인과 요약에는 LLM 비용이 따름.
