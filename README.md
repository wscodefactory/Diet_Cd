# 근거식단 (Diet CD) · 프로토타입

연구자료를 참고해 사람 또는 반려동물에게 맞춘 식단을 구성하고, 추천 이유와 참고자료를 쉽게 보여 주는 서비스의 **웹 프로토타입**입니다.

> ⚠️ AI와 논문 검색은 연결되어 있지 않습니다. 식단은 규칙 기반 로직으로 만들고, 모든 참고자료는 `[예시]`로 표시된 가짜 데이터입니다.
> 비용이 드는 항목은 [docs/paid-items.md](docs/paid-items.md)에 기록만 해 두었습니다.

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 타입 검사 + 프로덕션 빌드
```

## 들어 있는 것

- **상단 메뉴로 사람 / 반려동물 전환**, 한국어 / English 전환
- **사람**: 신체정보, 목표, 활동량, 선호·비선호, 알레르기, 하루 예산, 주기(일수 또는 요일), 도시락 여부 입력
- **반려동물**: 여러 마리 등록, 동물마다 조건과 식단을 따로 저장. 종·나이로 생애 단계(성장기/성년기/노령기)를 구분해 그에 맞는 예시 자료만 참고
- **결과 화면 순서**: 음식 사진(자리)과 구성 → ① 식단·도시락 구성 → ② 제공량·영양 → ③ 추천 이유 → ④ 반영 조건·제외 식재료 → ⑤ "참고한 연구 및 자료 보기" 버튼(펼침)
- **변경** 버튼으로 조건(알레르기·비선호·종)에 맞는 대안 메뉴/재료 선택
- **연구 카드**: 제목, 연도, 출처, 원문 링크, 대상, 반영 내용, "연구에서 확인한 내용"과 "AI가 적용한 판단" 구분, 적용 범위, 한계. 신뢰도 점수는 만들지 않음
- 반응형: 데스크톱은 입력/결과 2단, 모바일은 1단
- 디자인: 사람용 화이트+주황, 반려동물용 크림·살구·주황

## 구조

```
src/
  App.tsx                 화면 전환, 상태, localStorage 저장
  i18n.ts                 한/영 문구
  types.ts                공통 타입 (Plan 모델)
  engine/person.ts        사람 식단 규칙 (AI 자리)
  engine/pet.ts           반려동물 식단 규칙 (AI 자리)
  data/*.ts               예시 메뉴·재료·참고자료
  components/             입력 폼, 결과 화면, 연구 카드
docs/paid-items.md        유료 항목 기록
```

실제 AI를 붙일 때는 `buildPersonPlan` / `buildPetPlan`이 돌려주는 `Plan` 형태를 그대로 유지하면 화면은 바꾸지 않아도 됩니다.
